# Nail Clicker

クッキーのかわりに**釘**をひたすら打つ、ブラウザで遊べるクリッカーゲームです。
[Cookie Clicker](https://orteil.dashnet.org/cookieclicker/) のオマージュ作品です。

## 遊び方

1. 画面左の釘をクリックすると、「カンッ」と釘が 1 本増えます。
2. 集めた釘で、右の「施設」を買います。施設は自動で釘を増やしてくれます。
3. 条件を満たすと「強化」が現れます。買うと施設やクリックが強くなります。
4. どんどん釘を増やして、地下都市「アガルタ」を目指しましょう。

進み具合は 60 秒ごとと、画面を閉じるときにブラウザへ自動でセーブされます。
「データを消す」ボタンで最初からやり直せます。

## 起動方法

`index.html` をブラウザで開くだけで遊べます。インストールやビルドは必要ありません。

## 主な要素

- **施設（10 種類）**
  金づち → 大工さん → 釘打ち機 → 工務店 → 釘工場 → 釘銀行 → 神社 → 陰陽師の屋敷 → 地下探査機 → 地下都市「アガルタ」
- **強化（110 個）**
  - 金づちの強化：クリックと金づちを強くする
  - 各施設の強化：施設ごとに 10 段階。その施設の生産量が 2 倍になる
  - 大工さんの組み合わせ強化：大工さんとほかの施設を一緒に強くする
  - 手袋の強化：毎秒の生産量に応じて、クリックが強くなる
- **大きな数の表示**
  1 万以上の数は「1.23万」「750億」「3,750穣」のように日本語の単位で表示します。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `data.js` | 施設・強化の名前、説明文、数値 |
| `main.js` | ゲームの動き（計算、ショップ、セーブ） |
| `変更案.md` | これから入れる変更点のまとめ |
| `CLAUDE.md` | Claude Code 向けの作業ガイド |

## 使用技術

HTML / CSS / JavaScript のみ（ライブラリなし）。セーブデータはブラウザの `localStorage` に保存します。
